## Stop disposition

The candidate passed its complete local gate and every hosted Linux, Windows, extras,
Docker, and focused exact-linear check. Fresh exact-head review nevertheless returned
`INVALID`.

The binding-specific command could recompute the exact construction and independent
Fraction check before emitting the existing generic `CompressionValidationRecorded`
event. The event itself did not preserve the family, analysis, and check inputs. Replay
or direct evolution therefore could establish only self-consistency of referenced
records, not correspondence to the exact computation. A correct repair requires a new
binding-specific immutable validation event carrying sufficient replay material, but
event-schema changes were explicitly outside this Goal.

The Goal was stopped rather than widened. Candidate code and all returns remain on the
retained branch. No G3A-L code, dependency, event, CI gate, or claimed capability entered
protected `main`; RCI-051--RCI-053 and the linear part of RCI-054 remain deferred.
