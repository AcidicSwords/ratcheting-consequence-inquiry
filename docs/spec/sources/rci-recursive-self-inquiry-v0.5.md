# Recursive self-inquiry source for RCI v0.5

Status: preserved repository capture of the user-supplied project-level recursion
directive. This file is provenance; the normalized live authorities are
`RCI_Project_Spec.tex`, `PLAN.md`, `AGENTS.md`, ADR-0012, ADR-0013, and the active Goal.

The decisive obligation is:

> Find the smallest currently missing distinction, question, method, representation,
> or implementation capability whose acquisition would materially improve the
> project's ability to produce its next warranted successor.

The repository itself is treated as an RCI binding. Candidate changes are actions;
compiler, tests, property checks, solvers, benchmarks, primary literature, reference
implementations, fresh review, runtime execution, and CI are independently constrained
returns; a branch is a candidate realization; protected merge is promotion; rollback
and reopening conditions are retained residue.

The recurrence is:

```text
RECONSTRUCT
-> FIND CONSEQUENTIAL SELF-LIMITATION
-> TEST QUESTION/PROBE BASIS
-> BIND NATIVE METHOD
-> PROPOSE SUCCESSOR
-> ATTACK
-> SEAL DISCRIMINATOR
-> ACTUALIZE THROUGH NOT-ITSELF
-> COMPARE
-> CLASSIFY DEFORMATION
-> IMPLEMENT IN ISOLATION IF REQUIRED
-> VERIFY
-> RATCHET
-> RETAIN / CLEAN
-> GENERATE NEXT QUESTION
-> RECUR
```

The process must distinguish changes to theory, question/probe repertoire, method
repertoire, and implementation. It must challenge rather than assume roadmap order,
ask which established field natively owns a surviving relation, preserve exact returns
before interpretation, seal an implementation Goal before editing, and retain an
explicit frontier when successors are incomparable. It returns `Unknown` rather than
manufacturing skepticism when no lawful discriminator or method is available.

The development candidate may not change its own sealed Goal or incumbent acceptance
contract, erase failing evidence, grant itself new permissions, or promote itself.
Replacement requires predecessor preservation or an explicit disposition, a typed
strict gain, independent evidence, and protected promotion. Each completed cycle records
what became a regression, invariant, ADR, requirement, question, method binding,
reacquisition scaffold, or reopening condition, then recurs only on consequential
residue.

This source also identifies recurring coding-agent failure modes that the repository
protocol should externalize rather than pretend to remove from the model: context loss,
self-confirming tests, roadmap inertia, category collapse, acceptance drift, broad
over-editing, and false continuity across tasks.
