\subsection{A Question-Driven, Proof-Producing Architecture for

\textbf{Suggested filename:} \texttt{RCI\_Project\_Spec.md}\\
\textbf{Status:} Project specification / formal design document\\
\textbf{Version:} 0.3

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{Abstract}\label{abstract}

Ratcheting Consequence Inquiry (RCI) is a domain-agnostic architecture for
recursive inquiry in which questions are lawful relational probes over an
evolving state. A question does not merely request information. It binds
referents, exposes a relation as open, constrains what kind of claim an answer
may instantiate, shapes the locally active semantic field, and determines which
later operations may consume the result.

RCI separates five structures that are commonly conflated:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  semantic generation --- proposing candidate distinctions, mechanisms,
  examples, counterexamples, transformations, explanations, prerequisites,
  methods, and other content;
\item
  question structure --- determining which relational role is being probed and
  which prior objects are bound;
\item
  perception --- repeated application of stable relational probes to an
  evolving state, with comparable returns retained in order so persistence,
  change, recurrence, boundary crossing, covariation, and path dependence can
  become visible;
\item
  formal control --- composing claims, preserving guards, generating and
  scheduling obligations, refining and compressing representations, selecting
  native discharge mechanisms, and localizing failures;
\item
  warrant --- deciding which provisional claims may alter retained knowledge.
\end{enumerate}

Version 0.3 treats prediction, action--return contingency, reconstruction,
memory consolidation, selective retention, and learned perceptual coordinates
as executable runtime distinctions rather than as additional universal
cognitive primitives. Predictive processing, active inference, complementary
learning systems, pattern separation/completion, reconsolidation, and
developmental theories may motivate or specialize implementations, but RCI
imports only the relations whose absence would create a protected operational
failure.

The central architectural move remains:

\[
\boxed{
Q_\tau
:
\Sigma
\rightsquigarrow
\operatorname{Claim}[\tau]
}
\]

rather than:

\[
Q_\tau:\Sigma\rightsquigarrow\tau.
\]

The question makes the answer relationally addressable; it does not make the
answer true. Generated payloads are provisional. Independently constrained
proof, computation, execution, retrieval, observation, experiment, or another
licensed return is required before a candidate may enter retained hard
knowledge.

Version 0.3 adds a second use of question structure. A stable question contract
may also act as a recurrent probe. If the same relational projection is applied
to comparable states:

\[
H_q^t
=
\langle e_{t_1},e_{t_2},\ldots,e_{t_n}\rangle,
\]

the ordered trace becomes an ordinary queryable object. The existing inquiry
machinery can then ask what persisted, what changed, where a boundary was first
crossed, what covaried, what dissociated, and whether path or order mattered.
Perception is therefore not introduced as an independent trusted faculty. It is
a derived consequence of stable relational projection plus ordered comparable
returns.

The active semantic field is question-conditioned. A probe can make structures
that are distant under ordinary linguistic continuation locally adjacent when
they bear on the same open relation, while occluding structure that cannot
currently change the protected consequence. RCI distinguishes:

\[
\boxed{
\Sigma
=
A_{q,\Phi}
\;\dot\cup\;
U_{q,\Phi}
\;\dot\cup\;
I_{q,\Phi}
}
\]

where \(A\) is presently active/relevant, \(U\) has relevance not yet
established, and \(I\) is warranted irrelevant relative to the current probe
and protected consequence profile. Only the last class is aggressively hidden,
and every consequential occlusion carries a reopening condition.

The architecture therefore supports two simultaneous movements:

\[
\boxed{
\text{semantic expansion along the open question}
\qquad\text{and}\qquad
\text{contextual compression orthogonal to it}.
}
\]

RCI combines this question-conditioned semantic control with established
machinery from relational semantics, abstract interpretation, predicate
abstraction, CEGAR, active automata learning, IC3/PDR, DPLL(T), constrained
Horn clauses, predicate transformers, conflict minimization, assumption-based
truth maintenance, interpolation, controller refinement, optimization,
retrieval, experiment, and domain-native methods. The generic controller does
not replace stronger native machinery. It identifies the open relation,
establishes applicability, invokes a suitable native method or backend, and
brings the guarded return back into the evolving inquiry state.

The resulting recurrence is:

\[
\boxed{
\textbf{ORIENT}
\to
\textbf{PROBE}
\to
\textbf{COMPARE}
\to
\textbf{DISTINGUISH}
\to
\textbf{DEFORM}
\to
\textbf{ATTACK}
\to
\textbf{ACTUALIZE}
\to
\textbf{DISCHARGE}
\to
\textbf{LEARN}
\to
\textbf{REMEMBER}
\to
\textbf{REORIENT}.
}
\]

The process need not be followed as a rigid global workflow. The current
relational state determines which operation is locally warranted. Its core
implementation criterion remains:

\[
\boxed{
\textbf{the inquiry must remain lawful even when semantic generation and
perceived patterns are wrong.}
}
\]

Its epistemic criterion remains:

\[
\boxed{
\textbf{only independently warranted consequential deformation enters retained
knowledge.}
}
\]

\section{Part I --- Project Thesis}\label{part-i-project-thesis}

\subsection{1. Core claim}\label{core-claim}

Inquiry advances by discovering which distinctions change protected
consequences and eliminating distinctions that do not.

The two primitive epistemic movements are:

\[
\boxed{
\text{remove unsupported possibilities}
}
\]

and

\[
\boxed{
\text{remove false equivalences}.
}
\]

The central ratchet is:

\[
\boxed{
\textbf{Never retain a reasoning step merely because content was generated.
Retain it only if it produces a warranted consequential change.}
}
\]

Candidate generation may expand arbitrarily.

Repeated lawful probing may also expand perceptual access. A stable question
contract can be applied again after the state changes, and its ordered returns
can expose persistence, change, recurrence, covariation, and path dependence
that no isolated answer contains. Such perceived patterns are still candidate
claims until independently warranted.

Retained inquiry must ratchet.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{2. Questions as control
operators}\label{questions-as-control-operators}

Natural-language questions are treated as executable control operators
over an evolving inquiry state.

A question does not merely request information.

It establishes:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  which prior objects are being related;
\item
  which relation is being requested;
\item
  which kind of answer may lawfully be created;
\item
  which subsequent operations may consume that answer.
\end{enumerate}

For example, the surface question

\begin{quote}
Can the result still hold without this?
\end{quote}

corresponds formally to a necessity-counterexample obligation.

The controller already knows:

\begin{itemize}
\tightlist
\item
  the protected consequence \(C\);
\item
  the proposed necessity \(N\);
\item
  that a positive answer is being offered as a candidate member of
  \(C\land\neg N\).
\end{itemize}

The language model need not express the logical form itself.

A question also induces a temporary semantic coordinate system. Relative to a
protected consequence profile, it makes structures locally relevant when they
can change a live completion, its applicability, its interpretation, or its
warrant. Structures that cannot presently do so may be occluded from the active
field, but current non-activation is not evidence of permanent irrelevance.

For a recurrent probe, question identity additionally supplies a stable axis of
comparison across state revisions. The same relation can therefore be observed
again without inventing a new semantic coordinate system at every step.

Thus:

\[
\boxed{
\textbf{the question carries structural semantics and orients attention;
the answer supplies local semantic content.}
}
\]

and:

\[
\boxed{
\textbf{repeated comparable applications of the same relational probe create
an ordered perceptual trace.}
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{3. Trusted control, untrusted
payload}\label{trusted-control-untrusted-payload}

The central separation is:

\[
\boxed{
\text{lawful question composition}
\neq
\text{truth of answer payload}.
}
\]

A generated answer may be:

\begin{itemize}
\tightlist
\item
  correct;
\item
  incomplete;
\item
  vague;
\item
  overly broad;
\item
  contradictory;
\item
  mis-scoped;
\item
  semantically incoherent;
\item
  or wrong.
\end{itemize}

The controller nevertheless remains well-defined because the answer
initially becomes:

\[
\operatorname{Claim}[\tau],
\]

not an established object of type \(\tau\).

Only later may it become:

\[
\operatorname{Candidate}[\tau],
\]

and eventually:

\[
\operatorname{Warranted}[\tau].
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{4. The project objective}\label{the-project-objective}

The project is to build a system in which a general semantic model
supplies candidate content while a formal controller:

\begin{itemize}
\tightlist
\item
  determines what relational object should be sought next;
\item
  compiles that need into a plain-language question;
\item
  records the answer under the type implied by that question;
\item
  composes the resulting claim with earlier commitments;
\item
  deliberately seeks counterexamples and contradictions;
\item
  localizes whatever fails;
\item
  asks the next question implied by that failure;
\item
  invokes formal or external machinery only when needed;
\item
  generalizes warranted returns;
\item
  compresses distinctions that are warranted irrelevant under the current
  protected consequence;
\item
  preserves undetermined relevance rather than silently discarding it;
\item
  reuses stable question contracts when repeated observation is more valuable
  than a new framing;
\item
  retains ordered probe histories and lets those histories become ordinary
  objects of inquiry;
\item
  retrieves distant semantic or domain-native structure by relational fit
  rather than vocabulary alone;
\item
  and recursively repeats the process.
\end{itemize}

The intended outer loop is:

\[
\boxed{
\text{obligation}
\to
\text{question}
\to
\text{claim}
\to
\text{composition}
\to
\text{return}
\to
\text{warrant}
\to
\text{update}
\to
\text{next obligation}.
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\section{Part II --- Formal Substrate}\label{part-ii-formal-substrate}

\subsection{5. Typed binding}\label{typed-binding}

An inquiry is conducted relative to a binding

\[
\boxed{
\mathfrak B
=
(\mathbf X,\mathcal L,\mathcal A,\mathcal U,\mathcal H,\mathcal E)
}
\]

where:

\begin{itemize}
\tightlist
\item
  \(\mathbf X=\{X_\tau\}\) is the family of typed carriers;
\item
  \(\mathcal L\) is the available relational language;
\item
  \(\mathcal A\) is the family of admissible arrangement deformations;
\item
  \(\mathcal U\) is the family of admissible successions;
\item
  \(\mathcal H\) is the protected consequence horizon;
\item
  \(\mathcal E\) is the family of available independent discharge
  mechanisms.
\end{itemize}

An inquiry does not assume the existence of:

\begin{itemize}
\tightlist
\item
  a metric;
\item
  probability;
\item
  temporal order;
\item
  determinism;
\item
  causality;
\item
  scalar utility;
\item
  continuity;
\item
  total comparability;
\item
  or complete observability.
\end{itemize}

Such structure may be added only when warranted by the binding.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{6. Typed relations}\label{typed-relations}

For carriers \(X,Y\in\mathbf X\), a relation is

\[
R:X\rightsquigarrow Y
\]

with

\[
R\subseteq X\times Y.
\]

Relations compose:

\[
S\circ R
=
\{(x,z):\exists y,\ xRy\land ySz\}.
\]

For a relation

\[
R:X\rightsquigarrow Y
\]

and a target predicate \(Q\subseteq Y\), define the existential
predecessor:

\[
\boxed{
\Diamond_R(Q)
=
\{x:R[x]\cap Q\neq\varnothing\}
}
\]

and universal predecessor:

\[
\boxed{
\Box_R(Q)
=
\{x:R[x]\subseteq Q\}.
}
\]

When execution must exist:

\[
\boxed{
\operatorname{Must}_R(Q)
=
\operatorname{Dom}(R)\cap\Box_R(Q).
}
\]

These satisfy:

\[
\Diamond_{S\circ R}
=
\Diamond_R\circ\Diamond_S
\]

and

\[
\Box_{S\circ R}
=
\Box_R\circ\Box_S.
\]

This is the mathematical basis of succession, backward prerequisite
propagation, reachability, and actualization.

Kleene algebra with tests supplies an established algebraic basis for
compositional reasoning over program-like actions and embedded
predicates. {[}R1{]}

\section{Part III --- Protected
Consequence}\label{part-iii-protected-consequence}

\subsection{7. Consequence profile}\label{consequence-profile}

Let

\[
\Phi:X\rightsquigarrow Z
\]

be the current protected consequence profile.

A focal binary consequence is

\[
C:X\to\{0,1\}.
\]

Define

\[
C^+=C^{-1}(1),
\qquad
C^-=C^{-1}(0).
\]

The consequence polarity is relational rather than intrinsically
normative. Either side may be desired, undesired, neutral, unknown, or
merely contrasting.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{8. Problem and non-problem}\label{problem-and-non-problem}

If the inquiry begins from a recognized problem predicate

\[
P\subseteq X,
\]

then the first opposite class is simply

\[
\boxed{
\neg P.
}
\]

No concrete solution exemplar is required.

However:

\[
\neg P
\]

is only the provisional non-problem class.

Further protected consequences may distinguish acceptable resolution
from merely absence of the original problem.

Thus:

\[
\boxed{
\text{problem recognition supplies an opposite pole,
not necessarily a complete solution specification.}
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\section{Part IV --- Consequence Equivalence and
Distinction}\label{part-iv-consequence-equivalence-and-distinction}

\subsection{9. Consequence equivalence}\label{consequence-equivalence}

For protected continuations \(h\in\mathcal H\), let

\[
J_h:X\rightsquigarrow Z_h.
\]

Define:

\[
\boxed{
x\equiv_{\mathcal H}y
\iff
\forall h\in\mathcal H,
\quad
J_h[x]=J_h[y].
}
\]

Therefore:

\[
x\neq y
\]

does not imply

\[
x\not\equiv_{\mathcal H}y.
\]

The consequence-relative state space is

\[
\boxed{
X/{\equiv_{\mathcal H}}.
}
\]

This is the formal basis of RCI compression.

For deterministic sequential systems, this resembles the
continuation-based equivalence underlying Myhill--Nerode; Angluin's
\(L^*\) algorithm actively learns such behaviorally distinct states by
membership/equivalence queries and counterexamples. {[}R2{]}

For explicit relational systems, efficient partition-refinement methods
such as Paige--Tarjan compute coarsest relational partitions. {[}R3{]}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{10. Elementary distinction}\label{elementary-distinction}

Let

\[
d:X\to D.
\]

If

\[
d(x)\neq d(y),
\]

then the elementary distinction is:

\[
\boxed{
(x,d,y).
}
\]

This is triadic:

\begin{itemize}
\tightlist
\item
  first relatum;
\item
  second relatum;
\item
  common relation under which they differ.
\end{itemize}

The triad is not an additional algorithmic primitive. It is the minimum
geometry of a distinction.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{11. Tetradic refinement}\label{tetradic-refinement}

Introduce a second binary distinction

\[
D:X\to\{0,1\}.
\]

The joint refinement is:

\[
\boxed{
\langle C,D\rangle
:
X\to\{0,1\}^2.
}
\]

Its realized image is:

\[
\boxed{
T_{C,D}
=
\operatorname{im}\langle C,D\rangle.
}
\]

The logical cells are:

\[
C\land D,
\]

\[
C\land\neg D,
\]

\[
\neg C\land D,
\]

\[
\neg C\land\neg D.
\]

The existence of two distinctions does not imply that all four cells are
realizable.

A missing cell is an inquiry target.

The recursive geometry is therefore:

\[
\boxed{
\text{triad}
\to
\text{second distinction}
\to
\text{tetradic refinement}
\to
\text{residual}
\to
\text{new triad}.
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\section{Part V --- Arrangement and
Succession}\label{part-v-arrangement-and-succession}

\subsection{12. Arrangement}\label{arrangement}

Arrangement concerns differences among realizations.

For a reference arrangement \(r\), let

\[
\preceq_A^r
\]

be a binding-supplied preorder.

\[
x\preceq_A^r y
\]

means that \(x\) preserves at least as much relevant arrangement
structure of \(r\) as \(y\).

No numerical distance is required.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{13. Succession}\label{succession}

Each

\[
u\in\mathcal U
\]

is represented as

\[
R_u\subseteq X\times X.
\]

A succession path

\[
\pi=(u_1,\ldots,u_n)
\]

has relation:

\[
R_\pi
=
R_{u_n}\circ\cdots\circ R_{u_1}.
\]

A binding may supply a path preorder:

\[
\preceq_S.
\]

Arrangement minimality and succession minimality are distinct.

\[
\boxed{
\operatorname{MinArrangement}
\neq
\operatorname{MinSuccession}.
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\section{Part VI --- The Central Inquiry
Geometry}\label{part-vi-the-central-inquiry-geometry}

\subsection{14. Stretch within a consequence
class}\label{stretch-within-a-consequence-class}

The first geometric pressure is:

\[
\boxed{
\text{maximize variation while consequence remains fixed.}
}
\]

Given current predicate basis \(B\),

\[
\Delta_B(x,y)
=
\{p\in B:p(x)\neq p(y)\}.
\]

For \(x\in C^b\),

\[
\boxed{
\operatorname{Stretch}_B(x)
=
\operatorname{Max}_{\subseteq}
\{
\Delta_B(x,y):
C(y)=C(x)
\}.
}
\]

The purpose is to destroy false necessities and accidental correlation.

Generation therefore prefers cases that:

\begin{itemize}
\tightlist
\item
  preserve consequence;
\item
  differ strongly in arrangement;
\item
  differ strongly in succession;
\item
  violate the current explanation;
\item
  need not be realistic;
\item
  may be extreme or degenerate.
\end{itemize}

The generation law is:

\[
\boxed{
\textbf{Generate for discrimination, not plausibility.}
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{15. Squeeze across consequence
classes}\label{squeeze-across-consequence-classes}

The second pressure is:

\[
\boxed{
\text{minimize deformation while consequence changes.}
}
\]

For \(x\in C^b\),

\[
\boxed{
\operatorname{Squeeze}_B(x)
=
\operatorname{Min}_{\subseteq}
\{
\Delta_B(x,y):
C(y)\neq C(x)
\}.
}
\]

More generally, under an arrangement deformation preorder:

\[
\boxed{
\operatorname{Cross}_{C,\rho}(x,b)
=
\operatorname{Front}_{\preceq_\rho^x}
\{
y:
C(y)=b
\land
\operatorname{Adm}_\rho(x,y)
\}.
}
\]

where:

\[
\operatorname{Front}_{\preceq}(S)
=
\{s\in S:\nexists s'\in S,\ s'\prec s\}.
\]

The boundary law is:

\[
\boxed{
\textbf{Between opposite consequences, preserve everything possible
and minimize the change that flips the consequence.}
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{16. Bidirectional reversal}\label{bidirectional-reversal}

For every positive anchor:

\[
x^+\in C^+,
\]

ask for a minimal reversal into

\[
C^-.
\]

For every negative anchor:

\[
x^-\in C^-,
\]

ask for a minimal reversal into

\[
C^+.
\]

Thus inquiry probes:

\[
\boxed{
C^+\to C^-
}
\]

and

\[
\boxed{
C^-\to C^+.
}
\]

For problems:

\[
P\to\neg P
\]

and:

\[
\neg P\to P.
\]

The boundary is learned from both directions.

\section{Part VII --- Factor Discovery}\label{part-vii-factor-discovery}

\subsection{17. Candidate factor}\label{candidate-factor}

Let

\[
h:X\to H
\]

be a candidate representation.

Define its factorization defect:

\[
\boxed{
FD_\Phi(h)
=
\{
(x,y):
h(x)=h(y)
\land
\Phi(x)\neq\Phi(y)
\}.
}
\]

If:

\[
FD_\Phi(h)=\varnothing,
\]

then:

\[
\boxed{
\Phi=d\circ h
}
\]

for some decoder \(d\) on the declared scope.

Representations are ordered by factorization:

\[
\boxed{
h_1\preceq h_2
\iff
\exists m,\ h_1=m\circ h_2.
}
\]

Inquiry seeks a coarsest or nondominated factor that:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  preserves protected distinctions;
\item
  eliminates unnecessary distinctions;
\item
  remains noncircular.
\end{enumerate}

Abstract interpretation provides the established lattice-theoretic
framework for sound abstraction and approximation, including
abstraction/concretization relations and fixed-point semantics. {[}R4{]}

\section{Part VIII --- Mandatory
Falsification}\label{part-viii-mandatory-falsification}

\subsection{18. Necessity}\label{necessity}

Suppose:

\[
C\Rightarrow N.
\]

The corresponding counterexample region is:

\[
\boxed{
C\land\neg N.
}
\]

The claim is attacked by attempting to realize that region.

If realized:

\[
C\not\Rightarrow N.
\]

If independently established empty:

\[
C\land\neg N=\varnothing,
\]

necessity is warranted relative to scope.

Failure to find a counterexample is not itself proof.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{19. Sufficiency}\label{sufficiency}

Suppose:

\[
S\Rightarrow C.
\]

Attack:

\[
\boxed{
S\land\neg C.
}
\]

If realized, sufficiency fails.

If independently established empty, the implication is warranted in
scope.

Thus:

\[
\boxed{
\textbf{every necessity generates its missing counterexample cell;}
}
\]

\[
\boxed{
\textbf{every sufficiency generates its missing counterexample cell.}
}
\]

SAT/SMT backends can execute these obligations directly once the
semantic claims have been reified into formulas. DPLL(T) provides a
modular architecture in which a general Boolean search procedure
cooperates with specialized theory solvers. {[}R5{]}

\boxed{

\subsection{21. Control certificate}\label{control-certificate}

Let \(S\subseteq X\) be a source region and \(T\subseteq X\) a target
region.

A succession \(\pi\) is a must-control certificate iff:

\[
\boxed{
S\subseteq\operatorname{MustPre}_\pi(T).
}

For one state:

\[
x\in\operatorname{MustPre}_\pi(T).

When reasoning happens on an abstraction, a separate
concrete-to-abstract control-refinement relation is required. Feedback
refinement relations were developed specifically to guarantee that
symbolic controllers synthesized over abstractions can be concretely

If the target cannot coexist with retained arrangement constraints,
identify a conflict.

Let:

\[
\Gamma_x
\]

be retained constraints and \(I\) the target relation.

A conflict:

\[
K\subseteq\Gamma_x\cup\{I\}

is minimal iff:

\[
K\text{ is inconsistent}
\]

and:

\[
\forall K'\subsetneq K,\quad
K'\text{ is consistent}.
\]

QuickXPlain is an established divide-and-conquer approach for extracting
preferred/minimal explanations or relaxations from overconstrained

\Pi(x,T)
=
\{

If:

\[
\Pi(x,T)=\varnothing,

Any missing predecessor becomes an inquiry obligation.

Suppose \(N\) is proposed as necessary to reach \(T\).

Define:

\[
Reach_{\neg N}(x)

as the region reachable while keeping \(N\) absent.

Then test:

\[
\boxed{
Reach_{\neg N}(x)\cap T.
}
\]

If nonempty, \(N\) is route-specific.

Only prerequisites that survive alternate-route attack are retained as
genuine requirements.

\subsection{33. Question contract}\label{question-contract}

Every question family is defined by:

\[
\boxed{
\mathcal Q
=
(

\tau_{in},
\tau_{claim},
Pre,
Render,
Bind,
Reify,
Check,
Update,
Next,
Probe
).
}
\]

Where:

\begin{itemize}
\tightlist
\item
  \(id\) identifies the question operator;
\item
  \(\tau_{in}\) specifies input referent types;
\item
  \(\tau_{claim}\) specifies the role of the claim produced;
\item
  \(Pre\) determines whether the question is well-typed;
\item
  \(Render\) generates ordinary-language wording;
\item

\item

\item

\item

\item

\item

\[
\boxed{

=

}

This operation does not assert:

\[

\]

It asserts only:

\[
\boxed{
\text{“payload }a\text{ was offered as an answer to a question of role }\tau.”}
\]

This operation must be total for ordinary answer payloads.

\[
\boxed{

:

\rightharpoonup

}
\]

Failure to reify is itself an inquiry event.

It may generate:

\begin{itemize}
\tightlist
\item
  clarification;
\item
  decomposition;
\item
  re-expression;
\item
  rebind;
\item
  or unknown.
\end{itemize}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36. Promotion law}\label{promotion-law}

A candidate becomes hard knowledge only through:

\[
\boxed{
Promote(c,\pi)
=
\lambda
}
\]

when:

\[
Check(\pi)=\top.
\]

The central safety rule is:

\[
\boxed{
\textbf{question type may create a claim;
only warrant may create a hard lemma.}
}
\]

\section{Part XIII-A --- Recurrent Probes and Perceptual
State}\label{part-xiii-a-recurrent-probes-and-perceptual-state}

\subsection{36A. Recurrent probe}\label{recurrent-probe}

A question contract may be designated a recurrent probe when repeated
applications are intended to observe the same relational projection over
comparable state revisions.

Probe identity is not merely stable wording. It requires stable relational role,
binding schema, comparison semantics, applicability guard, and protected
consequence horizon, or an explicit bridge proving that two changed bindings
remain comparable.

\[
\boxed{
SameProbe(e_i,e_j)
\Rightarrow
Comparable_{q,\Phi}(e_i,e_j).
}
\]

Canonical rendering is preferred for recurrent probes when wording stability
improves semantic comparability, but surface identity is neither necessary nor
sufficient for probe identity.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36B. Probe event}\label{probe-event}

For one application of probe \(q\), preserve:

\[
\boxed{
e_t=
(
q,
\beta_t,
S_t,
\mathcal F_t,
a_t,
E_t,
r_t,
\iota_t,
\omega_t
).
}
\]

Where:

\begin{itemize}
\tightlist
\item \(q\): recurrent question contract;
\item \(\beta_t\): bound referents and local guards;
\item \(S_t\): observed state revision;
\item \(\mathcal F_t\): semantic field actually supplied;
\item \(a_t\): generated semantic answer;
\item \(E_t\): evidence or return channels consulted;
\item \(r_t\): preserved independent raw return, when one exists;
\item \(\iota_t\): interpretation of that return;
\item \(\omega_t\): sequence order.
\end{itemize}

The constitutional separation is:

\[
\boxed{
\text{generated answer}
\neq
\text{environmental return}
\neq
\text{interpretation}
\neq
\text{warrant}.
}
\]

Repeated model answers can reveal patterns in the generated inquiry trace.
Perception of an independently constrained environment requires that the probe
events also retain independently produced repository, tool, proof, execution,
measurement, observation, experiment, retrieval, or other licensed returns.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36C. Probe trace}\label{probe-trace}

For recurrent probe \(q\):

\[
\boxed{
H_q^t
=
\langle e_{t_1},e_{t_2},\ldots,e_{t_n}\rangle,
\qquad
\omega_{t_1}<\cdots<\omega_{t_n}.
}
\]

A probe trace is an ordinary queryable carrier. No special trusted perception
operator is required. Existing question contracts may be applied to traces.
Examples include:

\[
Q_{Persistence}:H_q\rightsquigarrow Claim[Invariant],
\]

\[
Q_{ChangePoint}:H_q\rightsquigarrow Claim[Boundary],
\]

\[
Q_{Covariation}:(H_q,H_r)\rightsquigarrow Claim[Relation],
\]

and:

\[
Q_{Path}:H_q\rightsquigarrow Claim[PathDependence].
\]

The resulting perceived pattern remains provisional. A pattern seen in an
ordered trace does not become a warranted invariant merely because it is
salient to the semantic generator.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36D. Fresh observation and comparison}\label{fresh-observation-and-comparison}

Prior answers can improve comparison but can also anchor the next answer. When
the environment can be independently re-observed, RCI should prefer a two-stage
probe:

\[
\boxed{
\text{fresh observation}
\to
\text{trace comparison}.
}
\]

First obtain the current observation with previous semantic interpretations
withheld when practicable:

\[
a_t^0=Q_q(S_t,\mathcal F_t^0).
\]

Then compare the new event against prior history:

\[
p_t
=
Q_{Compare}(H_q^{t-1},e_t)
\rightsquigarrow
Claim[Pattern].
\]

This does not prohibit history-conditioned probing. It prevents continuity in
model wording from being silently mistaken for persistence in the observed
system.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36E. Active, undetermined, and irrelevant
structure}\label{active-undetermined-and-irrelevant-structure}

Relative to a current probe \(q\) and protected consequence profile \(\Phi\),
partition available semantic structure as:

\[
\boxed{
\Sigma
=
A_{q,\Phi}
\;\dot\cup\;
U_{q,\Phi}
\;\dot\cup\;
I_{q,\Phi}.
}
\]

Where:

\begin{itemize}
\tightlist
\item \(A_{q,\Phi}\): structure established or strongly implicated as capable
  of changing a live completion, applicability, interpretation, warrant, or
  protected successor consequence;
\item \(U_{q,\Phi}\): structure whose relevance has not yet been discriminated;
\item \(I_{q,\Phi}\): structure warranted irrelevant to the current probe and
  protected consequence under an explicit guard.
\end{itemize}

Only \(I_{q,\Phi}\) may be aggressively occluded as consequence-null. Each such
occlusion retains a reopening predicate \(\rho_x\):

\[
\boxed{
\rho_x(\Sigma,q,\Phi)
\Rightarrow
x\text{ returns to the active or undetermined field.}
}
\]

Therefore:

\[
\boxed{
\textbf{not currently perceived}
\neq
\textbf{warranted irrelevant}.
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36F. Question-conditioned semantic
field}\label{question-conditioned-semantic-field}

The semantic field supplied to generation may be constructed as:

\[
\boxed{
Context_t(q)
=
A_t(q)
+
History_t(q)
+
CrossProbe_t(q)
+
Retrieve_{rel}(q)
+
Methods(q)
+
Reopening_t(q).
}
\]

Where:

\begin{itemize}
\tightlist
\item \(History_t(q)\) contains relevant comparable events from the same probe;
\item \(CrossProbe_t(q)\) contains traces whose changes may covary with the
  current relation;
\item \(Retrieve_{rel}(q)\) retrieves semantic or documentary structure by the
  relation the question exposes, not only lexical similarity;
\item \(Methods(q)\) contains native methods whose input/output relation can
  discharge the open relation;
\item \(Reopening_t(q)\) exposes guards whose change could reactivate currently
  occluded structure.
\end{itemize}

A question therefore performs simultaneous semantic expansion and contextual
compression:

\[
\boxed{
\text{bring consequence-bearing distant structure inward}
\quad\land\quad
\text{push consequence-null structure outward without forgetting reopening}.
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36G. Perception as a derived
phenomenon}\label{perception-as-a-derived-phenomenon}

RCI does not postulate an infallible perceptual faculty. Computational
perception is the derived structure produced by:

\[
\boxed{
\text{stable relational projection}
+
\text{ordered comparable returns}
+
\text{retained difference}.
}
\]

A family of recurrent probes induces a time-indexed relational signature:

\[
\boxed{
\chi_t
=
(q_1(\Sigma_t),q_2(\Sigma_t),\ldots,q_n(\Sigma_t)).
}
\]

The ordered sequence \(\chi_1,\chi_2,\ldots\) forms a trajectory over which
persistence, transition, recurrence, covariation, and boundary crossing may be
proposed and tested. Probe dimensions that never distinguish protected
consequences may be compressed; newly exposed distinctions may generate new
probes. The perceptual basis is therefore itself subject to inquiry.

\section{Part XIII-B --- Prediction, Action--Return Reconstruction, and

\subsection{36H. Sealed prediction}\label{sealed-prediction}

A consequential probe or action may carry an explicit prediction of the class
of return expected before the environment is queried. The prediction is not
required for every operation, and it need not be probabilistic. Its role is to
make mismatch inspectable rather than retrospectively redefinable.

\[
\boxed{

=
(

attempt,
\widehat r,
\widehat C,
\epsilon,
scope,
basis
).
}

The seal must be fixed before the corresponding attempt produces a return:

\[
\boxed{
created(PredictionSeal)
<
created(ExternalReturn).
}
\]

After execution:

\[
\boxed{
\widehat r\neq r
\Rightarrow
Mismatch(\widehat r,r).
}
\]

A mismatch is itself a typed inquiry object. It does not automatically identify
which prediction premise failed.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36I. Three-sided transition}\label{three-sided-transition}

The fundamental learning transition is operationally three-sided:

\[
\boxed{
\Sigma_t
\xrightarrow{V_t}
A_t
\xrightarrow{E}
r_t
\xrightarrow{R}
\Sigma'_{t+1}
\xrightarrow{W}
\Sigma_{t+1}.
}
\]

Here \(V_t\) is an internally selected variation, probe, action, or attempted
transformation; \(E\) is an independently constrained environment or backend;
\(r_t\) is a raw return the system did not get to choose; \(R\) is
reconstruction/reconciliation; and \(W\) is warrant-controlled commit.

Thus:

\[
\boxed{
\text{selected variation}
\neq
\text{external return}
\neq
\text{reconstruction}
\neq
\text{warranted update}.
}
\]

The system learns from action--return contingencies, not merely from static
semantic answers.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36J. Reconstructive memory}\label{reconstructive-memory}

Operational memory is not defined primarily as replay of stored surface text.
Given cue \(c\), protected horizon \(\mathcal H\), current context \(\gamma\),
and resource budget \(K\), memory may reconstruct a working representation:

\[
\boxed{
\widehat x=G(m,c,\mathcal H,\gamma,K).
}
\]

The criterion is protected regenerative sufficiency, not literal historical
identity:

\[
\boxed{
\widehat x\equiv_{\mathcal H}x.
}
\]

Generated reconstruction detail is not historical fact merely because it
appears in a successful reconstruction.

A memory request returns a set of candidate reconstructions:

\[
\boxed{
Reconstruct(c,\mathcal H,\gamma,K)
=
\{\widehat x_1,\ldots,\widehat x_n\}.
}
\]

If all candidates lie in one protected consequence class, retrieval is resolved
for that continuation. Otherwise:

\[
\boxed{
\left|
Reconstruct(c,\mathcal H,\gamma,K)/{\equiv_{\mathcal H}}
\right|>1
\Rightarrow
\text{memory retrieval becomes inquiry}.
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36K. Episodic and semantic learning}\label{episodic-and-semantic-learning}

RCI separates rapid episodic retention from slower generalized semantic
promotion.

\[
\boxed{
ProbeEvent,\ ExternalReturn,\ Attempt
\longrightarrow
M_E
}
\]

may occur immediately, but:

\[
\boxed{
M_E\not\Rightarrow\Theta.
}
\]

Generalized semantic knowledge requires:

\[
\boxed{
M_E
\xrightarrow{Consolidate}
Claim[Generalization]
\xrightarrow{Attack+Warrant}
\Theta.
}
\]

A consolidation pass should interleave consequential recent episodes with
relevant older episodes, exceptions, and counterexamples; ask which relation
survives; attack that relation; and promote only what those returns warrant.
Consolidation may be triggered at obligation closure, before major compression,
under context-budget pressure, or at another explicit policy checkpoint.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36L. Pattern separation and completion}\label{pattern-separation-and-completion}

Memory supports two opposite operations.

If similar retained events have different protected consequences:

\[
\boxed{
Similar(e_i,e_j)
\land
Consequence_{\Phi}(e_i)\neq Consequence_{\Phi}(e_j)
\Rightarrow
Separate(e_i,e_j).
}
\]

Similarity must not erase the distinction.

Conversely, a partial cue may activate several retained packages. If all
completion candidates are protected-consequence-equivalent, one regenerative
working representative may be used. If not:

\[
\boxed{
\text{completion ambiguity}
\to
\text{discrimination obligation}.
}
\]

Hence:

\[
\boxed{
\textbf{SEPARATE WHAT PROTECTED CONSEQUENCE DISTINGUISHES;
COMPLETE WHAT A CONSEQUENTIAL CUE REQUIRES.}
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36M. Reconsolidation and versioned repair}\label{reconsolidation-and-versioned-repair}

Retrieval followed by protected mismatch may reopen retained knowledge, but it
must not destructively rewrite the historical object.

\[
\boxed{
\lambda_t
\to
Challenge(\lambda_t,r)
\to
MemoryPatchCandidate
\to
Warrant
\to
\lambda_{t+1}.
}
\]

The predecessor remains historically available with the guard, scope, and
warrant under which it originally stood. The triggering return does not choose
its own repair.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{36N. Retention and self-cleaning}\label{retention-and-self-cleaning}

Self-cleaning means minimizing active interference while preserving protected
regenerative competence and authoritative ancestry.

\[
\boxed{
RetentionPackage
=
(

\mathcal H,
regen,
neighbors,
warrant,
debt,
\rho,
fallback
).
}
\]

Permitted operations include dropping inactive candidates, retiring redundant
probes, chunking trace regions after regenerative checks, deactivating lemmas
whose guards fail, compressing consequence-null distinctions, and deleting
deterministically reconstructible caches.

Operational irrelevance alone never licenses deletion of authoritative
provenance.

\[
\boxed{
\textbf{REMOVE ACTIVE STRUCTURE THAT NO LONGER EARNS ITS INTERFERENCE COST,
WHILE PRESERVING RECONSTRUCTION, WARRANT, AND REOPENING.}
}
\]

\[
\boxed{
\text{learning what relation stands}
\neq
\text{learning how to perceive a relation}.
}
\]

The universal scheduler remains a nondominated frontier such as:

\boxed{

No global free-energy, scalar utility, neural architecture, sleep mechanism, or

\section{Part XIV --- Protocol Safety}\label{part-xiv-protocol-safety}

\subsection{37. Protocol-safety
proposition}\label{protocol-safety-proposition}

Assume:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  every question answer is wrapped as \(\operatorname{Claim}[\tau]\),
  never coerced directly into \(\tau\);
\item
  formal reification is partial and may fail safely;
\item
  candidate-store contradictions do not imply arbitrary claims;
\item
  hard theory updates require independent warrant;
\item
  warrant dependencies are acyclic;
\item
  perceived patterns over probe traces remain candidate claims until checked;
\item
  continuity of generated wording is never accepted as evidence that the
  independently observed system remained unchanged.
\end{enumerate}

Then arbitrary semantic payloads cannot by themselves make the hard
inquiry state formally unsound.

A bad answer may cause:

\begin{itemize}
\tightlist
\item
  bad candidate claims;
\item
  unproductive branches;
\item
  conflicts;
\item
  extra obligations;
\item
  failed reification;
\item
  or misleading provisional paths.
\end{itemize}

But it cannot lawfully become a hard fact merely by being generated.

This gives the key implementation principle:

\[
\boxed{
\textbf{the question graph must remain lawful even if every answer is wrong.}
}
\]

This does not guarantee useful progress. It guarantees containment of
semantic fallibility.

Every concrete transition must be represented abstractly:

\[

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{44. L4 --- Control refinement}\label{l4-control-refinement}

Any abstract control action used to guarantee a concrete outcome must

the guarantee to the concrete system.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{45. L5 --- Conservative
refinement}\label{l5-conservative-refinement}

If \(B_{t+1}\) refines \(B_t\), require a forgetting map:

\[
\boxed{
\rho_{t+1,t}
:
V_{t+1}\to V_t
}
\]

such that:

\[
\boxed{
\alpha_t
=
\rho_{t+1,t}\circ\alpha_{t+1}.
}
\]

Old abstraction is recoverable by forgetting newly introduced
distinctions.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{46. L6 --- Compression
exactness}\label{l6-compression-exactness}

A quotient:

\[
q:V_t\to V'
\]

may be used only if protected consequence factors through it:

\[
\boxed{
\widehat\Phi_t
=
\Phi'\circ q.
}
\]

If control or succession is protected, relevant transition behavior must
factor as well.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{47. L7 --- Hard-lemma
soundness}\label{l7-hard-lemma-soundness}

Every irreversible hard update requires adequate warrant:

\[
\boxed{
Check(\pi)=\top
\Longrightarrow
g\models_\sigma\ell.
}
\]

Proof-producing SMT systems and frameworks such as LFSC illustrate the
established pattern of complex solvers returning certificates that can
be checked by a smaller trusted mechanism. {[}R10{]}

The proof graph must remain acyclic.

\section{Part XXIV --- Question
Scheduling}\label{part-xxiv-question-scheduling}

\subsection{67. Dependency order}\label{dependency-order}

Define:

\[
q_i\prec q_j
\]

when the answer to \(q_i\) can change:

\begin{itemize}
\tightlist
\item
  the referent of \(q_j\);
\item
  whether \(q_j\) is well-typed;
\item
  what answers to \(q_j\) mean;
\item
  or which outputs are possible.
\end{itemize}

Questions related by \(\prec\) should normally be sequenced.

Independent questions may be batched.

Thus:

\[
\boxed{
\textbf{batch antichains; sequence dependencies.}
}
\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{68. Order robustness}\label{order-robustness}

For questions expected to be independent, compare:

\[
U_{q_2}(U_{q_1}(\Sigma))
\]

with:

\[
U_{q_1}(U_{q_2}(\Sigma)).
\]

If protected consequences differ, inquire whether:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  the underlying relations genuinely interact; or
\item
  the language model exhibits irrelevant order sensitivity.
\end{enumerate}

Question-order permutation is therefore itself a diagnostic.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{69. Question value}\label{question-value}

Without a justified scalar objective, retain nondominated questions.

Possible dimensions:

\begin{itemize}
\tightlist
\item
  cost;
\item
  expected discrimination;
\item
  expected generalizability;
\item
  risk;
\item
  destructiveness;
\item
  reversibility;
\item
  warrant quality;
\item
  prediction/return mismatch localization;
\item
  reconstructive fidelity under protected continuation;
\item
  consolidation error and exception retention;
\item
  probe-basis growth and retirement;
\item
  active-memory interference cost.
\end{itemize}

With a valid measure \(\nu\):

\[
q^\star
\in
\arg\min_q
\left[
Cost(q)
+
\lambda
\max_r
\nu
(
Q_t\cap[\![Gen(q,r)]\!]
)
\right].
\]

This is optional policy, not foundational structure.

\subsection{69A. Perceptual continuity}\label{perceptual-continuity}

Question scheduling has two legitimate pressures:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item maximize consequential discrimination of the current frontier;
\item preserve stable relational axes when another observation under an existing
  recurrent probe would make change, persistence, recurrence, or path dependence
  visible.
\end{enumerate}

Therefore:

\[
\boxed{
q^\star
\in
Frontier(
Discrimination,
Continuity,
Cost,
Risk,
Reversibility,
WarrantQuality
).
}
\]

If an existing recurrent probe already exposes the needed distinction, prefer
reusing it unless a new probe has a nondominated informational advantage. If no
existing probe can expose the distinction, derive the smallest new relational
probe and add it provisionally to the perceptual repertoire.

Stable axes should not become permanent dogma. Probe usefulness is itself
consequence-relative and subject to compression or reopening.

\subsection{104A. Recurrent perceptual questions}\label{recurrent-perceptual-questions}

These are derived question contracts over \(ProbeTrace\) carriers rather than new
trusted primitives.

\paragraph{Persistence.}

\textbf{Input:} \(H_q\)\\
\textbf{Output:} \texttt{Claim[Invariant]}

\begin{quote}
What has remained the same across comparable applications of this probe?
\end{quote}

\paragraph{Change.}

\textbf{Input:} consecutive comparable events\\
\textbf{Output:} \texttt{Claim[Difference]}

\begin{quote}
What changed in the current return relative to the previous comparable return?
\end{quote}

\paragraph{Change point.}

\textbf{Input:} ordered \(H_q\)\\
\textbf{Output:} \texttt{Claim[Boundary]}

\begin{quote}
At what transition did this relation first materially change?
\end{quote}

\paragraph{Covariation.}

\textbf{Input:} \((H_q,H_r)\)\\
\textbf{Output:} \texttt{Claim[Relation]}

\begin{quote}
What changed in these probe histories at the same consequential transitions?
\end{quote}

\paragraph{Dissociation.}

\begin{quote}
What changed while this probe's protected consequence remained the same?
\end{quote}

\paragraph{Recurrence.}

\begin{quote}
Has this relational pattern appeared earlier under a comparable probe state?
\end{quote}

\paragraph{Path dependence.}

\begin{quote}
Did apparently equivalent states produce different returns after different
succession paths?
\end{quote}

\paragraph{Novelty.}

\begin{quote}
What appears in this return that has not appeared in the comparable trace?
\end{quote}

Each answer is wrapped as a provisional claim and subjected to ordinary
variation, boundary, falsification, actualization, and warrant operations.

\section{Part XXVI --- Minimal Question
Kernel}\label{part-xxvi-minimal-question-kernel}

\subsection{105. Four primary question
families}\label{four-primary-question-families}

Most of the library can be regenerated from four primary pressures.

\subsubsection{Variation}\label{variation}

\[
\boxed{
\text{What can change while this consequence remains the same?}
}
\]

\subsubsection{Boundary}\label{boundary}

\[
\boxed{
\text{What is the least change that makes the consequence different?}
}
\]

\subsubsection{Falsification}\label{falsification}

\[
\boxed{
\text{Can the consequence still occur without this?}
}
\]

and:

\[
\boxed{
\text{Can this still occur without the consequence?}
}
\]

\subsubsection{Actualization}\label{actualization}

\[
\boxed{
\text{What would have to be true for this relation to hold here?}
}
\]

followed by:

\[
\boxed{
\text{Can it hold without that supposed requirement?}
}
\]

The same primary pressures may be applied to ordered probe traces. This
regenerates persistence, change-point, covariation, dissociation, recurrence,
novelty, and path-dependence questions without adding a new primitive
perception calculus.

Two additional questions complete the epistemic ratchet:

\[
\boxed{
\text{What does this return warrant beyond this single case?}
}
\]

and:

\[
\boxed{
\text{What distinction can now be forgotten, and what would make it matter again?}
}
\]

\section{Part XXVII --- Question-Only Executable
Form}\label{part-xxvii-question-only-executable-form}

The entire architecture may be driven by the following recursive
sequence:


What is unresolved?

What consequence makes the live alternatives different?

Which stable probe, if any, is already observing that relation?

What does that probe return now before comparison with its previous semantic
interpretations, where fresh observation is available?

What previous comparable returns to this same probe exist, in order?

What remained the same?

What changed?

Where did it first change?

What else changed at the same transition?

Has the same pattern appeared before?

What would make the consequence unmistakably true?

What would make its opposite unmistakably true?

What can be radically different while the consequence stays the same?

What can differ as little as possible while making the consequence flip?

What relation survives those comparisons?

Can the consequence still hold without that relation?

Can that relation still hold while the consequence fails?

What smaller relation survives both attacks?

Can any protected consequence distinguish cases that relation identifies?

If so, what missing distinction separates them?

If not, is the distinction warranted irrelevant, or merely of undetermined
relevance?

What condition would make an occluded distinction relevant again?

Does the surviving relation merely describe the consequence, or can it be
established?

What would have to be true for it to hold here?

Can it coexist with what is already here?

If not, what smallest conflict prevents it?

What smallest change dissolves that conflict?

If it can coexist, can it be reached?

If not, what would have to be true beforehand?

Can it be reached without that proposed prerequisite?

If not, what would establish the prerequisite?

What native method or independently constrained mechanism can answer the
remaining question?

What did that mechanism actually return?

What does that return warrant?

What broader relation follows for the same reason?

What would falsify that generalization?

Under what guard does it remain valid?

What can now be excluded?

What can now be merged?

What must now be split?

What belongs in ordered episodic probe memory?

What belongs in guarded semantic memory?

What useful question or method should become procedural memory?

What may now be occluded, and what would make it matter again?

Did this cycle produce perceptual, epistemic, or representational progress?

What consequential residual remains?

Which existing probe should observe it next?

If none is adequate, what smallest new relational probe would expose it?

Then recur.

\section{Part XXVIII --- Implementation

\subsection{106. Layer 1 --- Formal

\item

\item
  choose backends;
\item
  compute formal updates;
\item
  prevent candidate claims from becoming hard facts without promotion.
\end{itemize}

The formal controller should not depend on the language model
understanding the whole architecture.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{107. Layer 2 --- Question
compiler}\label{layer-2-question-compiler}

Input:

\[
O_t.
\]

Output:

\[
Q_\tau(args).
\]

Responsibilities:

\begin{itemize}
\tightlist
\item
  choose question role;
\item
  bind referents;
\item
  render plain-language form;
\item
  preserve role metadata;
\item
  resolve deixis such as ``this,'' ``that,'' and ``what changed?'' to
  explicit object IDs.
\end{itemize}

Surface wording may vary.

Formal question identity does not.

Two surface questions are equivalent when they instantiate the same
contract with the same bound arguments.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}


\subsection{107A. Layer 2A --- Probe and semantic-field
manager}\label{layer-2a-probe-and-semantic-field-manager}

Responsibilities:

\begin{itemize}
\tightlist
\item register recurrent probe contracts;
\item determine event comparability under explicit guards and bridges;
\item maintain ordered \(ProbeTrace\) objects;
\item construct question-conditioned active fields;
\item separate active, relevance-undetermined, and guarded-irrelevant structure;
\item expose relevant prior probe history after fresh observation when possible;
\item retrieve cross-probe traces whose changes may covary;
\item retrieve distant semantic/domain material by relational fit;
\item preserve reopening edges for occluded structure;
\item prevent generated continuity from masquerading as environmental persistence.
\end{itemize}

This layer need not determine whether a perceived pattern is true. It preserves
the comparison conditions under which such a claim is meaningful.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}


\subsection{107B. Layer 2B --- Prediction and attempt
manager}\label{layer-2b-prediction-and-attempt-manager}

Responsibilities:

\begin{itemize}
\tightlist
\item create immutable prediction seals before consequential attempts when a
  prediction is available;
\item bind each seal to the exact probe/action plan, scope, and basis claims;
\item record actualized attempts separately from proposed plans;
\item preserve external raw returns immutably before interpretation;
\item generate mismatch objects without assigning a cause prematurely;
\item prevent post-return mutation of the prediction, target, assumptions,
  method, or warrant policy.
\end{itemize}

This layer supplies the explicit action--return contingency channel.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{108. Layer 3 --- Semantic
generator}\label{layer-3-semantic-generator}

The language model receives:

\begin{itemize}
\tightlist
\item
  the question-conditioned active semantic field;
\item
  one question or a dependency-safe batch;
\item
  referent material;
\item
  relevant ordered prior probe history when comparison is intended;
\item
  cross-probe histories, reopening edges, and native method candidates only
  when they can change the open relation.
\end{itemize}

Its task is:

\[
\boxed{
\textbf{provide semantic content of the requested claim role.}
}
\]

It is not entrusted with:

\begin{itemize}
\tightlist
\item
  deciding what question comes next;
\item
  promoting its own answers to truth;
\item
  preserving formal consistency;
\item
  selecting its own warrant;
\item
  or changing protected consequences silently.
\end{itemize}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{109. Layer 4 --- Claim binder}\label{layer-4-claim-binder}

The binder creates:

\[
Claim_Q(a).
\]

It should perform minimal processing.

At the thinnest implementation, it needs only:

\begin{itemize}
\tightlist
\item
  question ID;

\section{Part XXVIII-A --- Native Method
Repertoire}\label{part-xxviii-a-native-method-repertoire}

\subsection{112B. Method contract}\label{method-contract}

The generic controller should not reproduce mature domain machinery when an
established native method already realizes the required relation. A method may
be registered by a compact relational certificate:

\[
\boxed{
\mathcal M
=
(
id,
X,
O,
Pre,
Vary,
Return,
Warrant,
Failure,
Bridge
).
}
\]

Where:

\begin{itemize}
\tightlist
\item \(X\): admissible input carriers;
\item \(O\): open relation the method is designed to establish or discriminate;
\item \(Pre\): applicability conditions and prerequisites;
\item \(Vary\): what the method varies, holds fixed, traverses, or decomposes;
\item \(Return\): native return type;
\item \(Warrant\): conditions under which that return can license a claim;
\item \(Failure\): characteristic failure and non-applicability modes;
\item \(Bridge\): neighboring methods or cross-binding transport relations.
\end{itemize}

Method selection is therefore relational unification rather than name matching:

\[
\boxed{
Shape(O_t)
\approx
InputOutputShape(\mathcal M).
}
\]

The semantic model may propose a distant method or precedent because a question
makes the underlying relation locally adjacent even when vocabulary is remote.
The controller checks applicability; the native method owns its mathematics;
the returned result is brought back with its scope, assumptions, residue,
provenance, and warrant.

Examples include formal solvers, numerical simulation, statistical inference,
optimization, experiment, repository execution, engineering analysis methods,
scientific instruments, retrieval systems, and human expertise. The repertoire
is open-ended and regeneratively extensible.

\section{Part XXXI --- Conflict
Handling}\label{part-xxxi-conflict-handling}

\subsection{115. Candidate contradiction}\label{candidate-contradiction}

If candidate claims \(c_i,c_j\) conflict:

\[
\boxed{
Conflict(c_i,c_j)
}
\]

is added.

Do not:

\begin{itemize}
\tightlist
\item
  delete both automatically;
\item
  choose one arbitrarily;
\item
  infer arbitrary claims.
\end{itemize}

Generate:

\[
\boxed{
ResolveConflict(c_i,c_j).
}
\]

Possible resolutions:

\begin{itemize}
\tightlist
\item
  refute \(c_i\);
\item
  refute \(c_j\);
\item
  narrow one scope;
\item
  introduce hidden guard;
\item
  distinguish meanings;
\item
  discover invalid counterexample;
\item
  rebind representation;
\item
  retain unresolved conflict.
\end{itemize}

higher-priority warrant failure.

inconsistent conjunction until the conflict is localized.

\item
  incompatible scopes;
\item
  changed context;
\item
  unsound backend;
\item
  incorrect abstraction;
\item
  hidden assumption mismatch.
\end{itemize}

If:

\[
\alpha(x)=\alpha(y)
\]

but:

\[
\Phi(x)\neq\Phi(y),
\]

the current abstraction is too coarse.

Seek:

\[
p(x)\neq p(y)
\]

and refine:

\[
B_{t+1}=B_t\cup\{p\}.
\]

\begin{itemize}
\tightlist

\item

\item

\end{itemize}

\[
\boxed{

\[
\boxed{

The representation is not monotonic.

The warrant store is.

\section{Part XXXV --- Stopping Law}\label{part-xxxv-stopping-law}

\subsection{121. Stop when}\label{stop-when}

Stop an obligation when one of the following holds:

\subsubsection{Satisfied}\label{satisfied}

The desired claim is adequately warranted.

\subsubsection{Impossible}\label{impossible}

The target is adequately shown impossible within the declared binding.

\subsubsection{Consequence-equivalent
residual}\label{consequence-equivalent-residual}

All remaining alternatives yield identical protected consequence.

\subsubsection{No available
discriminator}\label{no-available-discriminator}

No representable question or available backend can distinguish the
remaining alternatives.

The final status is then:

\[
\boxed{
\text{unknown under the present binding}
}
\]

rather than an invented conclusion.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

Positive warrant remains acyclic.

\subsection{141. Invariant VIII --- Unknown is
legal}\label{invariant-viii-unknown-is-legal}

Failure to distinguish is not converted into equivalence without
warrant.

Failure to find a counterexample is not converted into necessity.

adequate warrant.

\subsection{141F. Invariant XIV --- Reconstruction is not history}\label{invariant-xiv-reconstruction-is-not-history}

\subsection{141G. Invariant XV --- Episodic event is not semantic knowledge}\label{invariant-xv-episodic-not-semantic}

\[
\boxed{

Semantic promotion requires consolidation, challenge, and warrant appropriate

\subsection{141H. Invariant XVI --- Similarity cannot erase consequence}\label{invariant-xvi-similarity-cannot-erase-consequence}

Similarity, embedding proximity, lexical overlap, or shared surface structure
cannot merge episodes or states whose protected consequences differ.

\subsection{141I. Invariant XVII --- Reconsolidation is versioned}\label{invariant-xvii-reconsolidation-versioned}

A challenged retained relation may acquire a warranted successor, but the
historical predecessor and its original warrant ancestry are not overwritten.

\subsection{141J. Invariant XVIII --- Operational forgetting preserves provenance}\label{invariant-xviii-operational-forgetting-preserves-provenance}

Compression, retirement, cache deletion, and context occlusion cannot destroy
authoritative ancestry merely because it is not operationally active.

\subsection{141K. Invariant XIX --- New probes do not self-promote}\label{invariant-xix-new-probes-do-not-self-promote}

A generated perceptual coordinate becomes procedural knowledge only after
demonstrated nonredundant discrimination or control value under protected use.

\section{Part XXXIX --- Verification
Tests}\label{part-xxxix-verification-tests}

\subsection{142. Protocol tests}\label{protocol-tests}

A conforming implementation should pass the following.

\subsubsection{Arbitrary-payload safety}\label{arbitrary-payload-safety}

Feed arbitrary strings as answers to every question contract.

Expected result:

\begin{itemize}
\tightlist
\item
  candidate claims are created;
\item
  no crash from semantic ill-typing;
\item
  no automatic promotion to hard theory.
\end{itemize}

\subsubsection{Contradiction
containment}\label{contradiction-containment}

Create claims for \(P\) and \(\neg P\).

Expected result:

\begin{itemize}
\tightlist
\item
  conflict obligation;
\item
  no arbitrary derived claim.
\end{itemize}

\subsubsection{Necessity attack
completeness}\label{necessity-attack-completeness}

Whenever a claim is tagged as necessity, verify that an obligation
equivalent to ``consequence without necessity'' exists or is already
discharged.

\subsubsection{Sufficiency attack
completeness}\label{sufficiency-attack-completeness}

Whenever a claim is tagged as sufficient, verify that its opposite cell
is queried or discharged.

\subsubsection{Guard reopening}\label{guard-reopening}

Activate a lemma, invalidate its guard, and verify:

\begin{itemize}
\tightlist
\item
  lemma remains stored;
\item
  it ceases to constrain the active model;
\item
  dependent distinctions may reopen.
\end{itemize}

\subsubsection{Conservative refinement}\label{conservative-refinement}

Add a predicate and verify the old abstraction is recoverable through
forgetting.

\subsubsection{Compression safety}\label{compression-safety}

Attempt to merge consequence-distinct states and verify refusal.

\subsubsection{Description/control
separation}\label{descriptioncontrol-separation}

Supply a perfect predictor with no implementable transition and verify
that no control certificate is produced.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}


\subsubsection{Probe-trace comparability}\label{probe-trace-comparability-test}

Create probe events with identical surface wording but incompatible bindings.
The protocol must refuse to treat them as one comparable trace unless a bridge
is established.

\subsubsection{Fresh-observation isolation}\label{fresh-observation-isolation-test}

Where the environment can be independently re-observed, compare observations
made with and without prior semantic answers in context. A repeated wording
pattern alone must not be accepted as environmental persistence.

\subsubsection{Perception/warrant separation}\label{perception-warrant-separation-test}

Construct an ordered trace with an obvious but spurious pattern. The system may
generate \texttt{Claim[Invariant]} but must not promote it without licensed
warrant.

\subsubsection{Unknown-relevance preservation}\label{unknown-relevance-preservation-test}

Remove an item from the active field without establishing consequence-nullness.
The system must classify it as relevance-undetermined rather than permanently
irrelevant and must remain able to reactivate it.



\subsubsection{Prediction sealed before return}\label{prediction-sealed-before-return-test}

Verify that an actual return cannot modify the stored predicted consequence,
return class, acceptable variation, scope, or basis claims.

\subsubsection{Raw return is not interpretation}\label{raw-return-is-not-interpretation-test}

Provide a correct raw environment return and an intentionally wrong semantic
interpretation. The preserved return must remain unchanged and available for
later reinterpretation.

\subsubsection{Variation--return--reconstruction order}\label{variation-return-reconstruction-order-test}

The system must not learn from an external return that was never tied to an
actualized attempt under the relevant state revision.

\subsubsection{Cue is not memory}\label{cue-is-not-memory-test}

A cue-conditioned reconstruction need not reproduce historical surface form;
it must preserve the protected continuation required by the query.

\subsubsection{Reconstruction is not history}\label{reconstruction-is-not-history-test}

Generated detail introduced while reconstructing context must not acquire
historical standing automatically.

\subsubsection{Consequence-distinct similar episodes separate}\label{similar-episodes-separate-test}

Two highly similar episodes with different protected consequences must remain
distinguishable and generate a separator obligation if the current memory
representation would merge them.

\subsubsection{Ambiguous completion opens inquiry}\label{ambiguous-completion-opens-inquiry-test}

A cue producing multiple protected-consequence-distinct reconstruction classes
must create a discrimination obligation rather than selecting one silently.

\subsubsection{Episode does not self-consolidate}\label{episode-does-not-self-consolidate-test}

A new episodic event cannot enter generalized semantic memory solely because it
was observed once.

\subsubsection{Consolidation interleaves counterexamples}\label{consolidation-interleaves-counterexamples-test}

A generalization proposed from recent episodes must retrieve relevant older
exceptions or counterexamples when available before promotion.

\subsubsection{Retrieval mismatch reopens}\label{retrieval-mismatch-reopens-test}

A protected mismatch against retained knowledge must challenge or reopen that
knowledge and create a versioned candidate patch rather than mutating it in
place.

\subsubsection{Active compression preserves provenance}\label{active-compression-preserves-provenance-test}

Operational forgetting must not delete authoritative warrant ancestry.

\subsubsection{Compressed memory regenerates protected behavior}\label{compressed-memory-regenerates-protected-behavior-test}

A retention package must pass a reconstruction fixture for its declared
protected continuation before promotion.

\subsubsection{Forgetting witness reopens local compression}\label{forgetting-witness-reopens-local-compression-test}

When a newly protected consequence distinguishes hidden structure, reopen the
smallest responsible compressed region rather than the whole archive.

\subsubsection{Probe basis can grow}\label{probe-basis-can-grow-test}

A representation gap must be able to create a candidate probe or rebind
obligation.

\subsubsection{New probe cannot self-promote}\label{new-probe-cannot-self-promote-test}

A generated probe must not enter durable procedural memory until subsequent use
demonstrates protected discrimination and passes redundancy checks.

\subsubsection{Redundant probe can retire}\label{redundant-probe-can-retire-test}

A probe whose removal does not change protected continuation behavior may be
retired while preserving the history and conditions needed to restore it.

\subsubsection{Learning changes future inquiry}\label{learning-changes-future-inquiry-test}

A claimed learning transition must measurably alter later generation,
retrieval, discrimination, question scheduling, control, or reopening behavior;
otherwise it is retained content, not learned inquiry structure.

\section{Part XLIII --- Complete Compressed
Definition}\label{part-xliii-complete-compressed-definition}

Ratcheting Consequence Inquiry is a typed recursive inquiry process over an
adaptive relational state whose questions orient a consequence-relative
semantic field and whose recurrent probes can make change visible across
ordered state transitions.

It begins from a protected consequence distinction rather than requiring a
pre-specified concrete problem or solution. It reconstructs the smallest
working world needed for the present continuation, binds what currently
stands, exposes the consequential residual, and chooses or derives a relational
probe or action capable of discriminating the live alternatives.

Within a consequence class it varies aggressively to destroy accidental
commonality. Across consequence classes it changes minimally to expose the
boundary. Proposed necessities, sufficiencies, and prerequisites are attacked
through their missing counterexample cells. Description remains distinct from
control.

When useful, an expected return is sealed before actualization. The system then
acts, probes, executes, retrieves, experiments, observes, proves, or invokes a
native method. The raw return is preserved independently of the prediction and
of every later interpretation. Mismatch becomes an inquiry object.

The return does not directly rewrite state. It enters a reconstruction step that
generates candidate interpretations, repairs, splits, merges, guard changes,
rebinds, and residual obligations. Only independently licensed warrant may
commit a semantic delta.

Consequential events enter episodic memory quickly. General semantic knowledge
arises only through consolidation, counterexample exposure, and warrant.
Similar memories with different protected consequences are separated. Partial
cues may complete retained structure only when the remaining completions are
protected-consequence-equivalent; otherwise retrieval itself becomes inquiry.

Retained knowledge is versioned rather than destructively overwritten.
Protected mismatch reopens a relation and creates a candidate successor while
preserving historical ancestry. Active state is continuously compressed,
retired, deactivated, and reconstructed so long as protected future inquiry,
warrant, provenance, and reopening remain regenerable.

The perceptual basis is itself learnable. Repeated failure of the current probe
or representation basis creates a representation gap from which candidate new
probes, methods, distinctions, or rebindings may be generated. None of these
self-promote: they become durable only after demonstrating nonredundant
protected discrimination or control value.

The universal kernel does not require predictive coding, free-energy
minimization, a neural memory architecture, sleep, developmental stages, or any
specific cognitive theory. Such theories may supply specialized bindings when
their native machinery is useful. The kernel requires only executable
distinctions whose loss would create protected failure.

In its minimal operational form:

\[
\boxed{
\begin{gathered}
\text{\textbf{RECONSTRUCT}}
\to
\text{\textbf{ORIENT}}
\to
\text{\textbf{PROBE/ACT}}
\to
\text{\textbf{PRESERVE RETURN}}\\
\to
\text{\textbf{COMPARE}}
\to
\text{\textbf{DEFORM}}
\to
\text{\textbf{ATTACK}}
\to
\text{\textbf{WARRANT}}\\
\to
\text{\textbf{LEARN}}
\to
\text{\textbf{SELF-CLEAN}}
\to
\text{\textbf{RECONSTRUCT}}
\to
\text{\textbf{RECUR}}
\end{gathered}
}
\]

The deeper developmental form is:

\[
\boxed{
\begin{gathered}
\text{\textbf{CHANGE ITSELF}}
\to
\text{\textbf{THROUGH NOT-ITSELF}}
\to
\text{\textbf{THROUGH ITSELF}}\\
\to
\text{\textbf{A CHANGED CAPACITY TO CHANGE AGAIN}}
\end{gathered}
}
\]

The last transition distinguishes learning from mere recurrence.

In its minimal language form:

\[
\boxed{
\begin{aligned}
&\textbf{What difference matters now?}\\
&\textbf{What stable probe already lets that difference be seen?}\\
&\textbf{What do the present state and prior comparable returns show?}\\
&\textbf{What can change without changing the consequence?}\\
&\textbf{What smallest change reverses it?}\\
&\textbf{What prediction would distinguish the live explanations?}\\
&\textbf{What did the independent return actually do?}\\
&\textbf{What changed relative to prediction and prior probes?}\\
&\textbf{What smaller relation survives the attacks?}\\
&\textbf{What does the return warrant changing?}\\
&\textbf{What belongs in episodic, semantic, procedural, or latent memory?}\\
&\textbf{What can now be compressed, and what would reopen it?}\\
&\textbf{Did the system learn a new fact, or a new way to perceive?}\\
&\textbf{What consequential residual remains?}
\end{aligned}
}
\]

The answer to the final question becomes the orienting distinction of the next
recursion.

\section{Project Definition}\label{project-definition}

\[
\boxed{
\textbf{RATCHETING CONSEQUENCE INQUIRY 0.3}
}
\]

is a proof-producing, property-directed, perception-capable,
question-driven refinement process over adaptive relational state.

Its architectural principle is:

\begin{center}
\fbox{\parbox{0.90\linewidth}{\centering\textbf{
RECONSTRUCTED OBLIGATION \(\to\) RELATIONAL ORIENTATION \(\to\)
QUESTION/PROBE/ACTION\\
\(\to\) QUESTION-CONDITIONED FIELD \(\to\) PROVISIONAL CLAIM/PREDICTION\\
\(\to\) ACTUALIZED VARIATION \(\to\) PRESERVED EXTERNAL RETURN\\
\(\to\) RECONSTRUCTION \(\to\) GUARDED WARRANT \(\to\) LEARNING/RETENTION\\
\(\to\) NEXT RECONSTRUCTED OBLIGATION
}}}
\end{center}

Its perceptual criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{Stable relational probes plus
ordered comparable returns make change and persistence addressable without
making the perceived pattern true.}}}
\end{center}

Its action--return criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{What the system predicts, what
it actualizes, what the environment returns, and what it later concludes must
remain separately inspectable.}}}
\end{center}

Its memory criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{Retain enough guarded structure
to reconstruct protected future inquiry and action; when reconstruction is
consequentially ambiguous, retrieve by inquiring rather than guessing.}}}
\end{center}

Its contextual criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{Make consequentially related
structure local; occlude only what the protected future cannot currently
inspect; retain how it would become relevant again.}}}
\end{center}

Its implementation criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{The process must remain formally
well-defined even when semantic generation, prediction, perception, or
reconstruction is wrong.}}}
\end{center}

Its epistemic criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{Only independently warranted
consequential changes enter retained semantic knowledge.}}}
\end{center}

Its regenerative criterion is:

\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering\textbf{When the current probes,
representations, memories, or methods cannot expose a protected distinction,
that insufficiency must itself become a well-formed inquiry capable of
extending or rebinding the system.}}}
\end{center}
